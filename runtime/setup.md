## How to setup GStreamer runtime

Downlad from URL (Windows) :
 > https://gstreamer.freedesktop.org/download/#windows

### Then choose this option:
- MSVC x86_64 (VS 2022, Release CRT)


### How to get the runtime files

- Step 1 :  After install  the GStremer then go to the file path you chose during installation process
- Step 2 :  Copy all GStreamer/ folder 
- Step 3 :  Paste GStreamer folder under runtime/
